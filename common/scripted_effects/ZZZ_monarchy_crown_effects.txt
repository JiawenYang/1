# ============================================================================
# ZZZ 君主制元首「加冕」效果（逐国一份）
#
# 作用：把该国君主的 character 补挂进国家，并按「每个意识形态大组一个块」把
# 5 个 country_leader 角色逐个 promote，使君主同时担任全部 5 个意识形态大组
# 各一个子意识形态的党首（同组只保留该国实际执政/最贴近的那一个）；
# 只有 ZZZ_monarchy_abolished 旗标生效后才停手。
#
# 注意：引擎按「角色」限制 —— 同一角色在同一意识形态大组内只能有一条
# country_leader，否则加载期告警
# "Character already has ideology (...) and trying to add ideology (...) which
# belongs to the same ideology group (...)"，且多余的块会被丢弃。
# 因此本文件与角色定义一律「每大组 1 条」，不再写 24 条。
#
# 所有效果名 / 字段名均来自基座实证：
#   promote_character = { character = X ideology = Y }
#     -> E:\SteamLibrary\steamapps\common\Hearts of Iron IV\documentation\effects_documentation.md:5149
#   recruit_character = X
#     -> 同上 :5696
#   5 个意识形态大组各取一个 token（democratic/communism/fascism/neutrality/nationalist）
#     -> E:\SteamLibrary\steamapps\workshop\content\394360\2777392649\common\ideologies\00_ideologies.txt
#
# 调用点：
#   history/countries/ZZ9 - 2017.txt（39 国 2017 块内直接 recruit + promote）
#   ZZZ_monarch_guard     -> common/scripted_effects/ZZZ_monarchy_effects.txt（on_government_change 触发）
#
# 更替（2026-11-07 追加）：
#   ENG/CAN/AST/NZL/ANT/BAH/BAR/BLZ/GRA/JAM/PAP/SOL/STK/STL/STV/TUL、JAP、DEN、
#   LUX、MAY、KUW、OMA 这 22 国改为「按旗标 + 日期」选择在位君主：
#     1) 事件先 retire 卸任者并 set_country_flag = ZZZ_monarch_<tag>_<name>
#     2) 本效果优先按旗标选人；旗标缺失时按现实日期兜底（复辟国家也能拿到
#        当时在位的现实君主，而不是 2017 年那位）
#     3) 其余国家仍维持单一代君主逻辑，不受影响
#   旗标/日期对照见 events/ZZZ_monarchy_succession.txt 与
#   common/scripted_effects/ZZZ_monarchy_succession_effects.txt
# ============================================================================
