# ============================================================================
# ZZZ 君主更替 · 运行期效果
#
# 由 events/ZZZ_monarchy_succession.txt 调用，事件根作用域为国家。
# 统一流程：
#   1) retire_character 卸任君主（退位/驾崩都用移除，不 kill 现任领袖）
#   2) set_country_flag 记录当前在位者，供 ZZZ_crown_<TAG> 选择
#   3) ZZZ_crown_<TAG> 复用现有加冕逻辑，按 5 个意识形态大组各 promote 1 条
#      （同组只保留该国实际执政/最贴近的子意识形态）
#
# 君主制已废除（ZZZ_active_monarchy 不成立）时整条更替不做任何事。
# ============================================================================
