# 俄罗斯 TFR 移植：普京康复路线（2026-10-24 测试版）

在最新仓库主线 `3504983` 上开发；此前法国移植已被团队合并。本次集中于俄罗斯国策、事件、机制，以及首次欧陆战争结果对法国的接线。

## 正常流程

1. 按现有组合启用千禧黎明、2017 Return 和东升西降，新开 2017 俄罗斯。2017–2019 继续使用原 MD 国策；普京的原生选举轮换被锁定。
2. 2020 年自动载入 TFR 俄罗斯初始国策，初始化杜马、寡头支持等相关机制，保留现有军队、科技及 MD 经济进度。
3. 普京确诊、病重事件保留原有辞职／硬撑分支，新增“接受治疗，康复后继续履行总统职责”。AI 权重为康复 1000、两个原选项各 1。选康复后约 28 天康复；已排队的原死亡事件会被拦截。
4. 普京康复后按初始国策推进。2022 年 2 月 24 日起可做“准备特别军事行动”，完成后真实宣战乌克兰；存在的顿涅茨克、卢甘斯克等乌东盟友加入俄方阵营与同一战争。
5. 俄方初期取得一定战果后，按南部陆桥和顿巴斯的地图据点近似判断停滞线。开战至少 21 天且控制六个据点中的四个，或乌克兰投降进度超过 30%，触发战线停滞。该判定是游戏近似，未修改地图边界。
6. 乌克兰战区所有标记州获得“未经计划的攻势”：进攻 -90%、突破 -90%，另有速度及组织恢复惩罚。事件切换为普京主持的国家整备树。
7. 整备树共 31 个必经国策，每个 35 天，总计 1085 天（约三年）。四条建设支线都需完成，随后进行战备评估、联合演练等收尾；最后一个国策为“最终攻势”。
8. “最终攻势”移除乌克兰战区全部本路线进攻限制，给予 240 天攻势加成。乌克兰投降进度达到约 70% 后加入现有北约阵营，北约参战并显示原版 TFR 风格的第一次欧陆战争超事件。另有即时投降回调，补接快速推进跳过阈值的情况。
9. 俄方胜利需要爱沙尼亚、拉脱维亚、立陶宛、波兰、罗马尼亚、匈牙利六国全部被击败。各国已投降、已经不存在，或已经是俄方附庸／同阵营盟友时视为目标达成。旧的波兰／匈牙利州占领判定已替换。俄方失败则要求莫斯科、圣彼得堡、罗斯托夫之一真正被与俄罗斯交战的敌国控制，俄方自己或盟友控制不会触发。
10. 对登记的交战双方执行停战，无关战争保留。战后按 TFR 的附庸／亲俄政权方式适配：波罗的海三国、波兰、乌克兰转为俄方附庸并加入集安组织；罗马尼亚、匈牙利触发原 TFR 的亲俄政权事件、保留形式独立并加入集安组织。斯洛伐克和保加利亚若在本次战争中投降，也使用相应亲俄政权安排。已被俄方吞并的相关国家，可从俄方拥有的核心领土恢复为附庸。俄胜调用法国 `france.203`，俄败调用 `france.215`。

## 整备数值

完成所有整备国策，累计提供工厂产出约 +60%、建筑速度 +50%、生产效率上限 +30%、科研速度 +20%；陆军攻击、突破、组织度分别约 +40%，补给消耗约 -25%，并补充合计约 100 万人力。最终攻势另提供临时攻击／突破 +35% 等加成。

上述数值尚需实机观察 MD 战斗和经济平衡，当前按需求提供较强的整备收益。

## 快速测试

请使用独立测试存档；不同死亡／康复选项、胜败结果不要在同一存档反复覆盖。

| 控制台命令 | 用途 |
| --- | --- |
| `event dsw_sov.1 SOV` | 立即进入 TFR 2020 阶段，可在 2017 测试存档中提前使用。 |
| `event dsw_tfr_russia.182 SOV` | 打开普京病重事件，选择新增康复选项。 |
| `event dsw_sov.3 SOV` | 选康复后立即结算康复，正常流程会等待约 28 天。 |
| `event dsw_sov.90 SOV` | 打开流程测试菜单，按顺序测试开战、停滞、新国策、最终攻势、北约介入，以及双方胜败。 |

先做前三步确认普京和初始树，再用测试菜单分段测试。法国需要已进入 2020 TFR 阶段；若尚未进入，可在法国测试存档使用 `event dsw_fra.1 FRA`。

## 修改范围和保留项

- 没有修改 `descriptor.mod`、地图文件、国家开局边界或其他国家的原国策。
- 共用文件仅 `common/scripted_effects/00_leader_setup_scripted_effects.txt` 新增 8 行俄罗斯领导人保护接线；原有法国保护和其他国家逻辑保留。
- 俄罗斯原疫情片段并入完整俄罗斯事件文件，避免重复事件 ID。
- TFR 俄罗斯事件使用独立的 `dsw_tfr_russia` 编号，保留千禧黎明原有的 `russia` 事件；与法国共用的人物沿用已有定义。
- 原版辞职／病逝后的统俄党、俄共树与相关内容一并导入；新的普京整备树单独改写文案及政策，不采用梅德韦杰夫的继任叙事和两党制改革。
- 某些源版缺失定义保留无额外数值的占位；尚未移植的外国事件、国策和可选增援保留接口。这些继承分支未完成全路线游戏测试，不能把本版视为整个 TFR 世界剧情的完整移植。
- 个别源版缺失图片使用通用图标；三张带梅德韦杰夫肖像的普京路线图标使用内置图像生成工具制作了普京版。文件和提示词见 `russia-putin-icons.md`。
