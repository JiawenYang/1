# 俄罗斯：特别军事行动、事件显示与独立工业恢复（2026-10-31）

## 特别军事行动的盟友限制

特别军事行动开始时，仅俄罗斯与乌克兰交战。现存 DPR、LPR、NOV 可继续保持俄方阵营关系，但不再由开战效果拉入战争；白俄罗斯和其他集安组织盟友也不在此时自动参战。

特别军事行动阶段，限制与俄罗斯有关的“召唤盟友”和“请求加入战争”外交入口。对白俄罗斯的召唤按钮动态显示“特别军事行动无法召唤盟友”；拦截原因也使用这段文字。直接对乌克兰发动战争的白俄罗斯、乌东各国入口同样受本阶段约束，其他国家的无关外交关系保持原有规则。

乌克兰加入北约、进入欧陆战争后，阶段限制解除，白俄罗斯自动加入俄方阵营及实际战争，余下俄方盟友按欧战参战流程处理。现有欧战存档可补接尚未参战的白俄罗斯。不存在的白俄罗斯不会被重新生成，已经与俄罗斯交战的白俄罗斯不会被强行改换阵营。

本次不使用白和平强行拆解已有联盟战争。已经把盟友拉入战争的旧存档，不能靠这次更新自动回退到双边战争；请读取特别军事行动开战前的存档复测。

## 工业独立恢复

工业国策只处理“紊乱的工业生产链”，不再恢复陆军攻击、防御、组织度、计划或补给数值。军事线继续只消减三军惩罚。工业初始各项幅度不超过 15%；通用和军工专项建造的初始叠加也不超过 15%。

| 工业修正 | 初始 | 全部工业整备后 |
| --- | --- | --- |
| 工厂产出 | −15% | +5% |
| 生产效率上限 | −10% | +5% |
| 生产效率增长 | −10% | 0 |
| 通用建造速度 | −10% | +5% |
| 军工专项建造速度 | −5% | 0 |
| 资源短缺生产惩罚 | +5% | 0 |

前段工业国策先恢复生产链。第 21、29、30 项提供的温和优化，要在第 2、14、20、22、23、24、25、26、27、28 项基础修复全部完成后才生效；提前完成优化国策会保存进度。自动建厂仍停用，旧版大幅工业、科研与军事正面奖励不恢复。

海军最终四项仍各保留 −5%；空军任务相关保留 −5%，王牌产生几率 −10%，事故率 +10%。陆军在所选路线全部 30 项完成后恢复正常。各精神的数值直接进入实际修正项，简介只讲背景。
