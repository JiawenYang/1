# 东升西降：法国 TFR 移植测试版

来源为 TFR 原版 1.0.9.1c（创意工坊 3350890356），适配现有千禧黎明／2017 Return 框架。本提交仅包含法国移植及其运行依赖。

## 立即测试

重启游戏，按现有的千禧黎明 + 2017 Return + 东升西降组合启用模组，新开 **2017 法国**。本次不需要同时启用 TFR 本体。

打开控制台，依次测试：

| 命令 | 用途 |
| --- | --- |
| `event dsw_fra.1 FRA` | 立即进入法国 2020 阶段：马克龙执政，载入 205 个国策的 TFR 初始树。可以在 2017 年直接使用这个测试入口。 |
| `event france.15 FRA` | 手动开始法国疫情事件，测试疫情任务和对应国策。 |
| `event dsw_fra.2 FRA` | 打开 TFR 原有的选举路线选择，完成所选路线的选前国策并进入 2022 选举。 |
| `event dsw_fra.10 FRA` | 在完成选举后，选择法国战胜／战败，测试国策切换与后续转线。 |
| `event dsw_fra.2017 FRA` | 在尚未进入 TFR 阶段时，单独测试 MD 的马克龙上台衔接。 |

也可以通过“法国路线测试”决议打开选举和战争结果入口。**不同选举结果、战胜和战败请分别使用独立测试存档**，原版 TFR 的一次性事件和互斥国策不会因重复输入命令自动重置。

先检查事件 1 后的领导人是否为马克龙、初始国策是否显示完整、图片和中文是否正常，再检查选举结果与人物是否对应。异常反馈最好带上事件编号、游戏日期和所选选项；相关运行错误可在游戏的 `logs/error.log` 中查看。

疫情事件后完成“成立科学委员会”，即可显示以“发行十年期国债”为起点的经济分支。

“法国路线测试”仅为测试决议，调用 TFR 原有的 `france.997` 调试菜单；正常游玩可跳过该入口。

## 正常时间线

2017–2019 保留千禧黎明法国内容；2017 年 5 月固定马克龙上台。2020 年自动切换 TFR 初始国策，再次设置马克龙执政并初始化法国相关机制；2022 年仍按 TFR 选举分支决定结果，保留现有军队、科技和军事工业进度。旧法国事件、决议和领导人轮换随后停用。

法国疫情、黄背心、军队政治、2022 选举，以及胜败、内战、共和／社会主义／民族主义等后续国策和相关事件已移入；合计 721 个 TFR 国策、413 个相关事件。地图州号、军队模板、人物编号、党派支持度和内阁槽位已作适配。党派沿用 MD 的全局分类，TFR 的党派支持度与领导人切换另行衔接；保留 MD 政府界面。选举由 TFR 事件推进，因此原生选举计时关闭。

## 本次保留的接口

第一次欧陆战争的爆发、作战和国际和约没有接入。测试事件 10 只调用法国胜败后的事件；后续主线可以从 `DSW_FRA_european_war_victory_hook` / `DSW_FRA_european_war_defeat_hook` 接入。

依赖尚未移植外国剧情的 14 个事件调用改为待接入标记；源版中不存在的西非法国国策树没有强行载入。外国国策条件保留对应的待接入标记。源版未提供定义的 16 个民族精神／特质保留 WIP 占位，未编造数值效果；少数缺失图片使用现有通用图标或可用肖像。

新建的分裂政权和相关路线国家只登记为休眠国家，开局不分配土地，不改变世界边界。
